01 — O QUE É UMA ÁRVORE?

O que é uma Árvore?

Uma árvore é uma estrutura de dados hierárquica — ao contrário de arrays e listas (que são lineares, um elemento após o outro), a árvore se ramifica como uma árvore genealógica ou um sistema de pastas do computador.

Pense no Windows Explorer: a pasta raiz (C:\) contém subpastas, que contêm outras subpastas, que contêm arquivos. Isso é uma árvore. Cada pasta é um nó, a ligação entre elas é uma aresta, e os arquivos sem subpastas são folhas.

── Lista linear (Array) ────────────────────── [10] → [20] → [30] → [40] → [50] Cada elemento aponta para o próximo. Sem ramificação. ── Árvore ────────────────────────────────────── [50] ← 1 raiz / \ [30] [70] ← ramifica em 2 / \ / \ [20][40] [60][80] ← folhas (sem filhos) Cada nó pode ter filhos. Cria hierarquia.

Por que usar árvores?

OperaçãoArrayLista LigadaÁrvore (BST)

Inserir em ordemO(n) — desloca elementosO(n) — encontra posiçãoO(log n) — segue galhos
Representar hierarquiaImpossível diretoImpossível diretoNatural e eficiente

🌳 Analogia do dia a dia Imagine um jogo de "adivinhe o número". Você pensa em um número de 1 a 100. Eu pergunto: "é maior ou menor que 50?" — se menor, descarto 50 números de uma vez. Depois: "maior ou menor que 25?" — descarto mais 25. Isso é a lógica de uma BST: a cada passo, você elimina metade dos candidatos. É por isso que a busca é O(log n).
02 — ANATOMIA

Anatomia de uma Árvore

Toda árvore é feita dos mesmos blocos. Aprenda o vocabulário uma vez e conseguirá entender qualquer árvore — seja BST, Heap, AVL ou Trie.

┌─────────────────────────────────────────────────┐ │ NÍVEL 0 (profundidade 0) │ └─────────────────────────────────────────────────┘ ┌──── 50 ────┐ ← RAIZ (sem pai) │ │ ┌───────────────────────────────────────────────────┐ │ NÍVEL 1 (profundidade 1) — filhos da raiz │ └───────────────────────────────────────────────────┘ ┌─ 30 ─┐ ┌─ 70 ─┐ ← nós internos │ │ │ │ ┌────────────────────────────────────────────────────┐ │ NÍVEL 2 (profundidade 2) — folhas │ └────────────────────────────────────────────────────┘ 20 40 60 80 ← FOLHAS (sem filhos) ARESTA: cada linha "─" ou "│" conectando pai → filho ALTURA da árvore = 3 níveis (raiz está no nível 0) ALTURA do nó 30 = 2 (tem 2 filhos abaixo dele)
🌱
Nó
Node

A unidade básica da árvore. Armazena um valor e referências para seus filhos.

👑
Raiz
Root

O nó do topo da árvore. É o único nó sem pai. Toda árvore tem exatamente uma raiz.

🍂
Folha
Leaf

Nó sem filhos. É o "fim do galho". Pode haver muitas folhas numa mesma árvore.

👨‍👧
Pai / Filho
Parent / Child

O nó de cima é o pai; os nós que ele aponta são seus filhos. Todo nó tem no máximo 1 pai.

🔗
Aresta
Edge

A ligação entre um pai e um filho. Em Java: o ponteiro (referência) de um nó para outro.

📏
Nível / Altura
Level / Height

O nível de um nó é a distância da raiz até ele. A altura da árvore é o nível máximo + 1.

Nó em Java Em código, um nó é simplesmente uma classe com o valor e referências para os filhos: class No { int valor; No esquerdo; No direito; } — três campos. Isso é tudo que você precisa para construir uma árvore binária inteira.
03 — ÁRVORE BINÁRIA

Árvore Binária

Uma árvore binária é aquela onde cada nó tem no máximo 2 filhos: um filho esquerdo e um filho direito. "Binária" = dois. Simples assim.

✓ Árvore Binária válida

[A] / \ [B] [C] / \ \ [D] [E] [F] Cada nó tem 0, 1 ou 2 filhos. → É binária ✓

✗ NÃO é binária

[A] / | \ [B] [C] [D] O nó A tem 3 filhos. → NÃO é binária ✗ (seria uma árvore n-ária)

Tipos de árvore binária

TipoRegraExemplo
PerfeitaTodos os níveis completamente cheios; todas as folhas no mesmo nível.A árvore com 50, 30, 70, 20, 40, 60, 80 do hero.
CompletaTodos os níveis cheios, exceto talvez o último (preenchido da esquerda).Heap utiliza esse formato.
DegeneradaCada nó tem só 1 filho. Vira uma lista ligada disfarçada.Inserir 10, 20, 30, 40 em sequência crescente na BST.
BalanceadaA diferença de altura entre subárvores esq/dir é pequena (≤1).AVL, Red-Black. Garante O(log n) sempre.
⚠ Armadilha: árvore degenerada Se você inserir valores em ordem crescente (10, 20, 30, 40, 50) em uma BST comum, a árvore vira uma lista ligada e a busca passa de O(log n) para O(n). É o pior caso de uma BST simples. AVL e Red-Black resolvem isso automaticamente.
04 — BST

BST — Árvore Binária de Busca

A BST (Binary Search Tree) é uma árvore binária com uma regra extra poderosa: todo valor à esquerda de um nó é menor que ele, e todo valor à direita é maior. Essa propriedade torna a busca extremamente rápida.

Regra BST: esq < nó atual < dir 50 / \ 30 70 ← 30 < 50 (esq) · 70 > 50 (dir) / \ / \ 20 40 60 80 ← 20,40 < 50 (sub-esq) · 60,80 > 50 (sub-dir) Inserindo 35: 35 < 50 → esquerda · 35 > 30 → direita · posição vazia → inserir! 50 / \ 30 70 / \ 20 40 / 35 ← novo nó inserido aqui

05 — PERCURSOS

Percursos (Traversals)

Percorrer uma árvore significa visitar todos os nós em alguma ordem. Existem três percursos clássicos, cada um com um propósito diferente — e todos são naturalmente implementados com recursão.

Em-Ordem
Inorder · LNR
Esq → Nó → Dir

Visita a subárvore esquerda, depois o nó atual, depois a subárvore direita. Em uma BST, retorna os valores em ordem crescente.

Uso: imprimir ordenado, converter BST em array.
Pré-Ordem
Preorder · NLR
Nó → Esq → Dir

Visita o nó atual primeiro, depois os filhos. A raiz é sempre o primeiro elemento — útil para copiar ou serializar a árvore.

Uso: copiar estrutura, salvar/exportar árvore.
Pós-Ordem
Postorder · LRN
Esq → Dir → Nó

Visita os filhos antes do pai. A raiz é sempre o último elemento — útil para deletar ou liberar memória da árvore de baixo para cima.

Uso: deletar árvore, avaliar expressões matemáticas.

Visualizando os 3 percursos na mesma árvore

Árvore: 50 / \ 30 70 / \ / \ 20 40 60 80 ── Em-Ordem (Esq→Nó→Dir) ──────────────────────── Visita: 20 → 30 → 40 → 50 → 60 → 70 → 80 Resultado: 20 30 40 50 60 70 80 ← ORDENADO! ✓ ── Pré-Ordem (Nó→Esq→Dir) ──────────────────────── Visita: 50 → 30 → 20 → 40 → 70 → 60 → 80 Resultado: 50 30 20 40 70 60 80 ← raiz primeiro ✓ ── Pós-Ordem (Esq→Dir→Nó) ──────────────────────── Visita: 20 → 40 → 30 → 60 → 80 → 70 → 50 Resultado: 20 40 30 60 80 70 50 ← raiz por último ✓
Macete para memorizar O nome diz onde o Nó atual é visitado:
Pré-Ordem = Nó é visitado antes dos filhos.
Em-Ordem = Nó é visitado entre os filhos (esq, nó, dir).
Pós-Ordem = Nó é visitado depois dos filhos.

Como a recursão implementa percursos

Java · Em-Ordem — anatomia da recursão 
void emOrdem(No no) {
    if (no == null) return;  // ← caso base: nó vazio, para a recursão

    emOrdem(no.esquerdo);           // 1. desce para a esquerda primeiro
    System.out.print(no.valor + " "); // 2. processa o nó atual
    emOrdem(no.direito);            // 3. desce para a direita
}

// Chamada: emOrdem(raiz)  →  visita todos os nós em ordem crescente
06 — INVERSÃO

Inversão de Árvore

Inverter (ou espelhar) uma árvore significa trocar os filhos esquerdo e direito de todos os nós. A árvore vira um reflexo no espelho. É um problema clássico de entrevistas técnicas — e a solução recursiva é elegante.

Original
50 / \ 30 70 / \ / \ 20 40 60 80
⇄
inverter
Invertida (espelhada)
50 / \ 70 30 / \ / \ 80 60 40 20
O que muda — e o que não muda A raiz continua sendo 50. A estrutura (forma) da árvore continua igual. O que muda é que o filho esquerdo de cada nó vira o direito, e vice-versa — recursivamente. Todos os galhos "viram no espelho". Experimente o botão ↔ Inverter no demo acima!

O algoritmo passo a passo

Chamada: inverter(50) Passo 1: temp = no.esquerdo ← guarda referência para o filho esquerdo (30) temp → 30 Passo 2: no.esquerdo = inverter(no.direito) ↳ chama inverter(70) recursivamente primeiro ↳ 70 já é folha? seus filhos 60 e 80 são trocados também ↳ retorna o nó 70 (agora com filhos invertidos) 50.esquerdo ← 70 (antes era 30) Passo 3: no.direito = inverter(temp) ↳ chama inverter(30) recursivamente ↳ 30 tem filhos 20 e 40 — eles são trocados 50.direito ← 30 (antes era 70) Caso base: if (no == null) return null; ← para a recursão em folhas
Java · Inverter árvore — solução recursiva 
No inverter(No no) {
    if (no == null) return null; // caso base: árvore/nó vazio

    No temp = no.esquerdo;          // guarda o filho esquerdo
    no.esquerdo = inverter(no.direito);  // esq ← invertido(dir)
    no.direito  = inverter(temp);        // dir ← invertido(esq)

    return no; // retorna o nó com filhos já trocados
}

// Chamada: raiz = inverter(raiz)
// Complexidade: O(n) — visita cada nó exatamente uma vez
Por que recursão funciona tão bem aqui O problema de inverter uma árvore é idêntico ao problema de inverter suas duas subárvores — e cada subárvore é idêntica ao problema original, só que menor. Isso é a definição de um problema recursivo: reduz ao mesmo problema em escala menor, com um caso base simples (null). A solução tem apenas 4 linhas.
07 — ALTURA E PROFUNDIDADE

Altura e Profundidade

Dois conceitos que iniciantes frequentemente confundem — mas são opostos: profundidade mede de cima para baixo (da raiz até o nó), e altura mede de baixo para cima (do nó até a folha mais distante).

50 / \ 30 70 / \ / \ 20 40 60 80 ─── Profundidade (distância da raiz até o nó) ──────────── Nó 50: profundidade = 0 (é a raiz) Nó 30: profundidade = 1 (1 aresta da raiz) Nó 20: profundidade = 2 (2 arestas da raiz) ─── Altura (distância do nó até a folha mais distante) ─── Nó 20: altura = 1 (folha — 0 filhos, altura = 1 por convenção) Nó 30: altura = 2 (tem 1 nível abaixo) Nó 50: altura = 3 (tem 2 níveis abaixo — ALTURA DA ÁRVORE)
Java · Calcular Altura 
int altura(No no) {
    if (no == null) return 0;
    int altEsq = altura(no.esquerdo);
    int altDir  = altura(no.direito);
    return 1 + Math.max(altEsq, altDir);
}
// O(n): visita cada nó 1 vez
Java · Contar Nós 
int contarNos(No no) {
    if (no == null) return 0;
    return 1
        + contarNos(no.esquerdo)
        + contarNos(no.direito);
}
// O(n): conta todos os nós
Por que altura importa? A altura determina a eficiência de todas as operações. Uma BST com altura h tem operações de O(h). Árvore balanceada: h ≈ log₂(n). Árvore degenerada: h = n. Para 1 milhão de elementos: log₂(1.000.000) ≈ 20 operações vs 1.000.000 operações. Diferença de 50.000x.
08 — CÓDIGO COMPLETO

Código Completo

Implementação completa em Java com todos os conceitos do guia: inserção, três percursos, inversão, altura e busca — tudo comentado linha a linha.

ArvoreBinaria.java · código completo e comentado 
// ── Classe que representa um Nó da árvore ───────────────
class No {
    int   valor;      // dado armazenado neste nó
    No    esquerdo;   // filho esquerdo  (valores menores)
    No    direito;    // filho direito   (valores maiores)

    No(int valor) {
        this.valor = valor;
        esquerdo = direito = null;
    }
}

public class ArvoreBinaria {

    No raiz; // raiz da árvore (ponto de entrada)

    // ── Inserção — regra BST: esq < nó < dir ────────────
    No inserir(No no, int valor) {
        if (no == null)
            return new No(valor);     // posição vazia → insere aqui!

        if (valor < no.valor)
            no.esquerdo = inserir(no.esquerdo, valor); // vai para esquerda
        else if (valor > no.valor)
            no.direito  = inserir(no.direito,  valor); // vai para direita
        // se igual: ignora (BST não permite duplicatas)

        return no;
    }

    // ── Em-Ordem: Esq → Nó → Dir  (saída ordenada) ───────
    void emOrdem(No no) {
        if (no != null) {
            emOrdem(no.esquerdo);
            System.out.print(no.valor + " ");
            emOrdem(no.direito);
        }
    }

    // ── Pré-Ordem: Nó → Esq → Dir  (raiz primeiro) ───────
    void preOrdem(No no) {
        if (no != null) {
            System.out.print(no.valor + " ");
            preOrdem(no.esquerdo);
            preOrdem(no.direito);
        }
    }

    // ── Pós-Ordem: Esq → Dir → Nó  (raiz por último) ─────
    void posOrdem(No no) {
        if (no != null) {
            posOrdem(no.esquerdo);
            posOrdem(no.direito);
            System.out.print(no.valor + " ");
        }
    }

    // ── Inverter (espelhar a árvore) ──────────────────────
    No inverter(No no) {
        if (no == null) return null;

        No temp   = no.esquerdo;
        no.esquerdo = inverter(no.direito);
        no.direito  = inverter(temp);
        return no;
    }

    // ── Altura da árvore ──────────────────────────────────
    int altura(No no) {
        if (no == null) return 0;
        return 1 + Math.max(altura(no.esquerdo), altura(no.direito));
    }

    // ── Buscar um valor na BST ────────────────────────────
    boolean buscar(No no, int valor) {
        if (no == null)           return false;  // não encontrou
        if (valor == no.valor)     return true;   // encontrou!
        if (valor < no.valor)
            return buscar(no.esquerdo, valor);    // busca esquerda
        return buscar(no.direito, valor);          // busca direita
    }

    public static void main(String[] args) {
        ArvoreBinaria arvore = new ArvoreBinaria();

        int[] valores = {50, 30, 70, 20, 40, 60, 80};
        System.out.println("Inserindo: 50, 30, 70, 20, 40, 60, 80");
        for (int v : valores)
            arvore.raiz = arvore.inserir(arvore.raiz, v);

        System.out.println("\n── Percursos ──");

        System.out.print("Em-Ordem:   ");
        arvore.emOrdem(arvore.raiz);
        System.out.println("← ordenado!");

        System.out.print("Pré-Ordem:  ");
        arvore.preOrdem(arvore.raiz);
        System.out.println();

        System.out.print("Pós-Ordem:  ");
        arvore.posOrdem(arvore.raiz);
        System.out.println();

        System.out.println("\nAltura:     " + arvore.altura(arvore.raiz));
        System.out.println("Buscar 40:  " + arvore.buscar(arvore.raiz, 40));
        System.out.println("Buscar 99:  " + arvore.buscar(arvore.raiz, 99));

        // Inverter e mostrar
        arvore.raiz = arvore.inverter(arvore.raiz);
        System.out.print("\nApós Inverter (Em-Ordem): ");
        arvore.emOrdem(arvore.raiz);
        System.out.println("← ordem decrescente!");
    }
}

10 — PRÓXIMOS PASSOS

Próximos Passos

Você dominou a base. Agora existem variantes especializadas de árvores — cada uma resolve um problema diferente de forma elegante.

Nível Intermediário
Árvore AVL

BST que se auto-balanceia após cada inserção ou remoção. Garante altura O(log n) no pior caso — acabando com o problema da árvore degenerada.

Auto-balanceamento
Nível Intermediário
Red-Black Tree

Outro método de auto-balanceamento. Usada internamente no Java (TreeMap, TreeSet). Menos rotações que AVL, preferida em sistemas de produção.

Java TreeMap/TreeSet
Nível Intermediário
Heap (Fila de Prioridade)

Árvore binária completa onde o maior (ou menor) elemento está sempre na raiz. Base da ordenação HeapSort e de filas de prioridade eficientes — O(log n) para inserir/remover.

PriorityQueue em Java
Nível Avançado
Trie (Árvore de Prefixos)

Árvore otimizada para strings. Cada nó representa um caractere. Usada em autocompletar, dicionários e mecanismos de busca. Busca de palavra em O(comprimento da palavra).

Strings e Autocompletar
Por onde começar? Depois deste guia, o próximo passo natural é implementar a remoção de nós na BST — é o algoritmo mais complexo da estrutura básica (precisa lidar com 3 casos: remover folha, remover nó com 1 filho, remover nó com 2 filhos). Depois disso, estude Heap — é usada em desafios de programação competitiva com frequência.
