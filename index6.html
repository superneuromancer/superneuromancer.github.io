Detalhe — operações CRUD dentro de FormUsuariosListar
+
INCLUIR
FormUsuariosListar → [INCLUIR] → FormUsuariosIncluir.abrir(this, loginOperador) → new FormUsuarioEditar(this, id=0) // modo inclusão → [preenche campos] → [SALVAR] → INSERT INTO tb_usuarios (...) → AuditoriaUtil.registrar("INCLUIR_USUARIO") → dispose() → isSalvo() = true → carregarUsuarios() // atualiza a grade
✎
EDITAR
FormUsuariosListar → [EDITAR] ou duplo clique → abrirFormEdicao() → obtém id da linha selecionada → new FormUsuarioEditar(this, id) // modo edição → carregarDados() // SELECT preenche campos → [edita campos] → [SALVAR] → UPDATE tb_usuarios SET ... WHERE usuario_id=? → AuditoriaUtil.registrar("EDITAR_USUARIO") → carregarUsuarios()
✕
EXCLUIR
FormUsuariosListar → [EXCLUIR] → FormUsuariosExcluir.excluir(this, loginOperador) → obtém id e nome da linha selecionada → JOptionPane.showConfirmDialog // confirmação obrigatória → DELETE FROM tb_usuarios WHERE usuario_id=? → AuditoriaUtil.registrar("EXCLUIR_USUARIO") → carregarUsuarios()
